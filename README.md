# sas_crm_pj
# 이커머스 고객 생애주기 관리 프로젝트 — 주차별 계획

> RFM × 군집분석 × 이탈예측 통합 마케팅 솔루션 (SAS 기반, 자격증 포트폴리오용 V2)
> 데이터: Onlinesales_info / Customer_info / Discount_info / Marketing_info / Tax_info (5개 테이블)

**핵심 원칙:** RFM은 별도 세그먼트가 아니라 군집분석의 입력 변수로만 사용 (중복 제거).
코호트·연관분석은 전체 레벨 보조 인사이트로 가볍게 (교차분석은 최소화).

---

## 문제 정의 및 데이터 이해

### Week 1 — 데이터 이해 및 정제
- [ ] 5개 테이블 `PROC CONTENTS`로 구조 파악
- [ ] `PROC MEANS`/`PROC FREQ`로 결측치·이상치 탐지 (수량 음수=반품, 평균금액 이상치 등)
- [ ] 테이블 간 정합성 체크 (거래 테이블의 고객ID가 Customer_info에 다 있는지 등)
- [ ] `DATA STEP`으로 정제, 반품/이상거래는 제외 대신 플래그로 보존

**산출물:** 정제 데이터셋, 데이터 프로파일링 보고서
**문제의식:** "정적인 세분화만으로는 고객의 현재 상태만 보이고, 향후 이탈 여부는 알 수 없다" — 이 문제를 8주 동안 풀어나감

---

## RFM 기반 군집분석 + 보조 인사이트

### Week 2 — 파생변수 및 RFM 설계
- [ ] `PROC SQL`로 Onlinesales_info 기준 고객별 RFM 지표 산출 (Recency/Frequency/Monetary)
- [ ] Customer_info(가입기간, 지역, 성별), Discount_info(쿠폰 활용률) 조인하여 파생변수 추가
- [ ] RFM은 **군집분석 입력 변수**로만 사용 (별도 등급표 만들지 않음 — 중복 방지)

**산출물:** RFM 지표 테이블, 파생변수 명세서

### Week 3 — 군집분석 (핵심 세분화 축)
- [ ] `PROC STDIZE`로 RFM 변수 표준화
- [ ] `PROC FASTCLUS`로 K-Means 군집화, CCC/Pseudo-F로 최적 K 결정
- [ ] 군집별 특성 프로파일링 (군집별 평균 R/F/M, 지역/성별 분포)

**산출물:** 최종 세그먼트(Cluster ID 부여 데이터셋) — **이후 모든 분석의 기준 세그먼트**

### Week 4 — 코호트·연관분석 (보조 인사이트)
- [ ] `PROC SQL` + `PROC SGPLOT`으로 전체 레벨 코호트 리텐션 히트맵 (가입월 기준, 배경 트렌드 파악용)
- [ ] `PROC ASSOC`으로 전체 연관 규칙 도출 + 군집별 상위 구매 카테고리만 간단 비교 (풀 교차분석 지양)

**산출물:** 코호트 리텐션 히트맵, 세그먼트별 상위 연관 상품 요약

---

## 전환: 예측 모델링으로 심화

### Week 5 — 이탈 예측 모델링 (머신러닝 도입)
- [ ] 이탈 타겟변수(Y) 정의 (예: 최근 N일 이상 미구매 = 이탈 위험)
- [ ] `PROC PARTITION`으로 train/valid 분할
- [ ] `PROC GRADBOOST`(SAS Viya) 또는 `PROC LOGISTIC`(베이스라인)으로 이탈 확률 예측 모델 학습
- [ ] Week 3 군집 결과를 예측 모델의 입력 변수로도 활용 (세그먼트 → 이탈 확률 연결)

**산출물:** 이탈 예측 모델(Score Code 포함)
**전환 포인트:** "현재 상태(군집)"에서 "미래 행동(이탈 확률)"으로 분석의 축이 바뀌는 지점

### Week 6 — 모델 평가 및 해석
- [ ] ROC/AUC, Recall 평가
- [ ] 변수 중요도 + PDP(Partial Dependence Plot)로 주요 이탈 요인 해석
- [ ] "어떤 군집이 이탈 위험이 높은지" 교차 확인 (Week 3 결과와 연결)

**산출물:** 성능 평가서(AUC-ROC, Recall), 주요 이탈 요인 리포트

---

## 결론: 통합 등급 설계 및 실행 전략

### Week 7 — 최종 등급 설계 및 액션 플랜
- [ ] 군집(Who) + 이탈확률(When) + 연관구매 패턴(What)을 결합해 최종 고객 등급 확정
- [ ] 등급별 실행 전략 매핑 (예: 이탈위험군 → 자동 윈백 쿠폰, 잠재충성군 → 업셀링)
- [ ] Marketing_info 활용해 등급별 획득 비용 대비 효과(ROI 초안) 계산

**산출물:** 최종 고객 등급 체계, 세그먼트별 액션 플랜

### Week 8 — 최종 보고서 및 발표자료
- [ ] KPI 가설 vs 실측치 비교 정리 (AUC-ROC, 잔존율 등)
- [ ] 전체 파이프라인(起承轉結) 스토리라인으로 최종 보고서 작성
- [ ] 전체 분석 결과를 AARRR 퍼널로 재정리 (새 분석 없이 기존 결과 재배치)
- [ ] 발표자료 정제

**산출물:** 최종 실행 기획서, 발표자료

**AARRR 재정리 매핑 (8주차 전용 — 새 계산 없음):**

| AARRR | 재사용할 기존 결과 |
| --- | --- |
| Acquisition | Marketing_info 분석의 CAC(고객획득비용) |
| Activation | 4주차 코호트분석의 가입~첫구매 소요일 |
| Retention | 4주차 코호트분석의 M+1/M+3 잔존율 |
| Revenue | 2주차 RFM의 Monetary, 7주차 ROI 계산 |
| Referral | 데이터 없음 → 한계점으로 명시, 향후 확보 필요 데이터로 제안 |

## 참고: 핵심 SAS 프로시저 매핑

| 단계 | SAS 프로시저 | 역할 |
| --- | --- | --- |
| 데이터 정제 | `PROC CONTENTS`/`MEANS`/`FREQ`, `DATA STEP` | 구조 파악 및 정제 |
| RFM/파생변수 | `PROC SQL` | 고객 단위 지표 생성 |
| 군집분석 (핵심) | `PROC STDIZE` + `PROC FASTCLUS` | 세그먼트 확정 |
| 코호트/연관 (보조) | `PROC SQL`+`SGPLOT`, `PROC ASSOC` | 배경 인사이트 |
| 이탈예측 (전환) | `PROC PARTITION`, `PROC GRADBOOST`/`LOGISTIC` | 미래 행동 예측 |
| 모델 해석 | 변수중요도, `PROC SGPLOT`(PDP) | 요인 설명 |

## KPI 목표치 (가설 — 5~6주차 실측 후 갱신)
- 이탈 예측 모델 AUC-ROC ≥ 0.85, Recall ≥ 0.80
- 이탈위험군 대상 타겟 프로모션 ROI 개선
- 코호트 M+1/M+3 잔존율 %p 향상
